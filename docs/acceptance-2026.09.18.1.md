## 已修复

- 仿真运行期间锁定编辑控件、风场切换和重复任务；关闭窗口不会直接中断服务器操作。
- 后台异常提示保留原始错误，完成或失败后恢复控件原状态。
- 本地和云端仿真拒绝跨风场选择目标 MAP；目标文件不存在时停止。
- 恢复备份检查文件所属风场，以及记录中的服务器和文件路径。
- 本地与 FTP 拷取在传输结束后检查源文件大小和修改时间，变化时保留断点并报告失败。
- FTP 断线和取消保留断点；明确拒绝 REST 的服务器改为重新下载完整文件。
- 主控整日期 FTP 扫描遇到不可读目录、未知大小或超深目录时报告失败，避免误报完整。
- 仿真服务器只接受 RFC1918 内网 IPv4，不解析域名。
- 构建使用独立输出目录，不结束运行中的程序，不清理旧成品；构建失败立即停止。
- 成品不打包运行时配置、日志、备份或历史下载目录。

## 验证边界

- 没有连接现场服务器，没有上传或还原现场文件。现场账号、目录权限、吞吐量及安全设备策略尚不能由本机测试证明。
- 完整性检查使用路径、大小及传输期间修改时间，不等同于服务器与本地逐文件内容哈希核对。
- 网络共享和映射盘由 Windows 提供；其实际网络路由和安全设备行为需要现场确认。
- 下载更新和仓库链接只有点击才打开浏览器；拷取过程不依赖互联网。
- 当前风场目录中的源文件是否最初已被他人仿真，需要可信原件或现场对比表证明，不能仅靠文件名确认。
