# 风机文件拷取工具

2026.09.19：大量文件或文件夹按数据量均衡分配给最多 3 条持续使用的连接。同一文件夹保留边界，失败时只重试失败文件。仍未完成会生成 `incomplete_时间.json`，记录源路径、目标、预期大小和原因，不含密码。

用于从瞬态、变桨日志、震动 SFTP 服务器和各风机主控中拷取指定日期、指定风机的文件。

## 内网安全限制

- 程序不包含互联网请求、更新检查、遥测或日志上传。
- 连接地址必须是 `10.x.x.x`、`172.16-31.x.x` 或 `192.168.x.x` 私有 IPv4。
- 域名和公网 IP 会被程序直接拒绝，避免 DNS 或公网连接。
- 所有组件都打包在 EXE 内，运行时不在线安装依赖。

## 已确认的数据规则

### 瞬态

- 协议：SFTP over SSH
- 默认服务器：`192.168.149.222:60022`
- 默认根目录：`/opt/goldwind/drbd_dataprocess/LocalData/HistoryFile`
- 服务器层级：`年份/分组/RealtimeData/日期/文件`
- 瞬态不限定后缀名，也允许无后缀文件。日期目录会递归扫描全部子文件夹；日期目录混放多台风机时，程序从文件名中的设备编号末三位筛选风机；如果“网络位置来源”路径里填写了 `{fan}` 或 `{fan3}`，则认为来源目录已按风机分开，会直接拷取该目录下普通文件。
- 如果现场已经能在资源管理器里直接打开瞬态服务器目录，可填写“网络位置来源”；填后优先从该路径拷取，空着才走 SFTP；路径支持 `{date}`、`{year}`、`{ip}`、`{fan}`、`{fan3}`。

输出层级：

```text
保存目录/transient/服务器IP/日期/原文件
```

界面也可改为“按 IP/风机号/日期”或“保留服务器目录”。

### 主控

- 主控把 `IP 前缀` 和 `风机号` 分成两个输入框；前缀只填三段（如 `192.168.151`），风机号框只填编号。单台填 `7`，连续填 `1-20`，不连续填 `1,3,8,13`
- 风机号列表同时接受英文逗号 `,`、中文逗号 `，`、英文分号 `;` 和中文分号 `；`，无需切换输入法
- 当前日志已验证可自动拷取的主控通道是 `FTP21`。`RDP3389` 是远程桌面可达，不等于 FTP；如果资源管理器已经能直接打开主控目录，也可填写“已有共享文件夹（可选）”。
- 默认远程路径：`/app/gw/ftp/log`，按现场主控 B/F/O 日志目录填写
- 如果现场已经能在资源管理器里直接打开服务器故障目录，可填写“网络位置来源”，程序会优先从这个路径找日期文件夹；映射盘、UNC 共享和 Windows 可复制的网络目录都可用，路径支持 `{ip}`、`{fan}`、`{fan3}` 占位符
- 支持 B、F、O 文件任意组合，或选择“整日期文件夹”拉取当天目录全部文件
- 支持文件名关键字过滤，例如 `VibrWarn,BladeLoad`
- 支持单台、连续多台和不连续多台；程序根据任务数量自动安排批量拷取
- 主控最多自动并行 4 台；瞬态、变桨和震动最多自动使用 3 条独立 SFTP 连接，每条连接拥有独立会话和目标文件
- 单台单日的瞬态或震动目录下有多个一级文件夹时，一个文件夹对应一个任务并行拷取；只有一个文件夹时才按文件并行。多风机或多类型任务已在外层并行时，子目录保持顺序，连接总数不会叠加。
- 单文件传输失败会自动重连并断点续传；并行目录失败后只重试该目录，降级成单连接顺序重试。任务结束会校验全部目标文件的路径和大小，目录无法读取或目标不完整会显示失败。
- 支持单日或日期范围
- 主控“测试主控 BOF”只测试第一台；程序依次尝试填写的共享文件夹、FTP21 和 Windows 系统共享，实际能访问日志目录的方式会被使用，某台失败会写日志并继续下一台。

输出层级：

```text
保存目录/master/F001_192.168.151.1/20260906/O|B|F/原文件
保存目录/master/F001_192.168.151.1/20260906/整日期文件夹原目录结构
```

### 变桨日志

- 默认地址：`192.168.180.风机号:22`
- 默认账号：`root`，默认目录：`/app/data/traceLog/`
- 只拷取文件名以 `PTYYYYMMDD_` 开头的日志，例如 `PT20260816_103222.897_60064.txt`

输出层级：

```text
保存目录/pitch/服务器IP/F001/日期/原文件
```

### 震动数据

- 默认服务器：`192.168.160.100:22`
- 默认目录：`/data/GwTempData/CMSDATA/`
- `BMSDATA`、`TMSDATA`、`WAVEDATA` 是三个同级目录，可单独勾选
- 目录规则：`类型/风场号/YYYY-MM/风场号+三位风机号/YYYY-MM-DD`
- 震动不限定扩展名；命中对应日期目录后会递归拷取全部子目录中的普通文件，并保留原相对目录，避免同名文件覆盖。
- 如果现场已经能在资源管理器里直接打开 CMSDATA 目录，可填写“网络位置来源”；填后优先从该路径拷取，空着才走 SFTP。

输出层级：

```text
保存目录/vibration/服务器IP/风场号/F001/日期/BMSDATA|TMSDATA|WAVEDATA/原文件
```

## 使用

运行交付目录中的 `风机文件拷取工具.exe`。瞬态、主控、变桨和震动的账号密码都可以在对应页面修改；点击“显示密码”可查看，点击“保存设置”后保存到当前 Windows 用户配置，关闭程序后仍保留。

瞬态、主控、变桨和震动页面各自提供“保存到”，可以在每次任务前重新选择任意本地盘或移动盘目录；四者分别记住上次位置。

每次任务会在保存目录生成 `拷取记录_日期时间.log`，记录非敏感连接参数、远程目录、日期/风场/风机/类型筛选、统计结果、断点、重连、跳过、失败和异常堆栈；密码不会写入日志。

风机号支持以下写法：

```text
1
1,3,8,13
1-20
```

日期支持 `YYYY-MM-DD` 或 `YYYYMMDD`，单次最多 366 天。默认不覆盖已有文件；传输使用 4 MB 分块，取消、断线或失败时保留 `.part` 和校验信息，下次按相同条件断点续传。远端文件在下载期间发生大小或修改时间变化时不会被当作成功，会保留断点并重试。

### 网络适配器

主窗口顶部的“网络适配器”窗口对应现场网卡配置流程：选择适配器、刷新列表、自动 DHCP/手动多个 IPv4、添加或删除地址行，以及风机/变桨/净空/雷达/变流/交换机/消防/振动快捷预设。每个快捷预设只对应一个 IP。手动地址只接受 RFC1918 私有 IPv4；读取是只读操作，点击“应用到系统”后才通过 UAC 修改选中 Windows 网卡。

程序仅接受内网 IPv4 地址，不解析域名、不访问互联网、不执行在线更新或遥测。传输前会统计所选文件和剩余写入量，并检查目标盘空间、保留 2 GB 安全余量。瞬态连接中断会自动重连最多 3 次；主控批量任务由程序自动调度，其他任务按稳定优先处理，进度限频刷新，运行期间阻止系统自动睡眠。该方式面向瞬态约 600 GB/月、主控约 10 GB/月以及半年到全年任务，不会把整个文件或整批数据装入内存。
