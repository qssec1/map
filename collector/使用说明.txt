风机文件拷取工具使用说明

一、运行要求
1. 支持 64 位 Windows 10 和 Windows 11。
2. 直接运行“风机文件拷取工具.exe”，无需安装 Python 或其他组件。
3. 程序仅连接内网 IPv4 地址，不包含互联网更新、遥测和日志上传功能。

二、公共设置
1. 日期格式支持 YYYY-MM-DD 和 YYYYMMDD，单次日期范围最长 366 天。
2. 风机号支持以下格式：
   单台：7
   连续多台：1-20
   不连续多台：1,3,8,13
3. 英文逗号“,”、中文逗号“，”、英文分号“;”和中文分号“；”均可作为分隔符。
4. 默认跳过已存在且大小一致的文件。需要重新考取时，可勾选“覆盖已有文件”。
5. 各功能的保存目录相互独立，可分别设置。

三、瞬态数据
1. 填写服务器、端口、账号、密码和风机号。
2. 可直接使用 SFTP，也可填写本机可访问的网络位置。
3. 支持按 IP/日期、IP/风机号/日期或服务器目录结构保存。
4. 不限制文件扩展名，按日期和风机号筛选文件，并递归读取日期目录下的全部子文件夹。

四、主控故障
1. “IP 前缀”只填写前三段，例如 192.168.151。
2. “风机号”只填写风机编号，不得填写完整 IP。
3. 支持 B、F、O 文件分类考取，也可选择“整日期文件夹”。
4. 可填写文件名关键字进行进一步筛选。
5. 程序自动使用可访问的共享目录、FTP 或系统共享来源。
6. “连接测试”和“端口诊断”只用于检查第一台风机。

五、变桨日志
1. “IP 前缀”只填写前三段，风机号单独填写。
2. 按所选日期筛选 PT 日期格式日志。
3. 支持单台、连续多台和不连续多台任务。

六、震动数据
1. 填写服务器、端口、账号、密码、风场号和风机号。
2. BMSDATA、TMSDATA、WAVEDATA 可单独或组合选择。
3. 不限制文件扩展名，递归考取服务器日期目录中的文件。
4. 可填写本机可访问的 CMSDATA 网络位置。

七、并发与失败处理
1. 主控故障最多自动处理 4 台并发任务。
2. 瞬态、变桨和震动最多自动使用 3 条独立连接。
3. 单台单日存在多个一级文件夹时，每个文件夹作为一个并发任务；只有一个文件夹时按文件分配任务。
4. 并发失败后，仅对失败任务执行单连接顺序重试；已成功任务不会重复考取。
5. 单连接重试仍失败时，程序记录失败原因并继续后续任务。
6. 未完成文件保留为 .part 断点文件，下次使用相同条件时继续传输。

八、输出与日志
1. 瞬态输出到 transient 目录。
2. 主控故障输出到 master 目录。
3. 变桨日志输出到 pitch 目录。
4. 震动数据输出到 vibration 目录。
5. 瞬态和震动保留源文件夹的相对路径；不同文件夹内的同名文件不会互相覆盖。
6. 每次任务生成独立考取日志。日志记录地址、目录、筛选条件和任务结果，不记录密码。

九、注意事项
1. 开始任务前确认日期、风机号、保存目录和可用磁盘空间。
2. 任务运行期间不要移动输出目录或删除 .part 文件。
3. 连接失败时，先查看任务日志和端口诊断结果。
4. 首次连接新的 SFTP 服务器时，程序会保存服务器主机指纹；指纹变化时应停止任务并核实服务器。
